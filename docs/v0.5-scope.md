# CSPR.trade MCP v0.5 — Scope Document

_Created: 2026-04-26 | Author: Jean Clawd (COO)_

## Background

v0.4.2 shipped with security fixes, serverInfo corrections, and the `get_native_cspr_balance` tool (task #924). v0.5 focuses on developer experience improvements that make the MCP more useful for AI agents.

## Shipped in v0.4.x → v0.5 Transition

- ✅ `get_native_cspr_balance` — native CSPR balance via node RPC (PR #14, merged 2026-04-26)
- ✅ CI matrix updated to Node 22 (astro 6.x requirement)

## v0.5 Roadmap

### 1. Improved Error Messages with Actionable Hints (Priority: High)
**Problem:** Current errors are generic (e.g., "request failed"). AI agents need actionable hints.
**Solution:** Catch common error cases and return structured, actionable messages.
**Examples:**
- Insufficient balance → "Balance is X CSPR but swap requires Y. Get balance with get_token_balance."
- Invalid token → "Token 'XYZ' not found. Use get_tokens to list available tokens."
- Slippage exceeded → "Trade failed: slippage exceeded 3%. Increase slippage_bps or reduce amount."

### 2. TypeScript Types Export for SDK Consumers (Priority: Medium)
**Problem:** External TypeScript consumers cannot easily import SDK types for type checking.
**Solution:** Export all public types from `packages/sdk/src/index.ts` with a dedicated types re-export.
**Deliverable:** `import type { SwapQuote, TokenBalance, ... } from '@make-software/cspr-trade-mcp-sdk'`

### 3. MCP Tool Input Validation with Better Error Messages (Priority: Medium)
**Problem:** Invalid inputs produce confusing downstream errors from the Casper RPC.
**Solution:** Add validation at tool entrypoints with clear error messages.
**Examples:**
- `amount: "abc"` → "amount must be a positive number, got: abc"
- `token_in == token_out` → "Cannot swap a token for itself"
- Negative slippage → "slippage_bps must be between 0 and 10000"

### 4. Token Address Annotations in Tool Descriptions (Priority: Low)
**Problem:** Agents guessing token names waste round-trips to get_tokens.
**Solution:** Embed most common token contract hashes in tool descriptions for CSPR, USDT, WCSPR.

## Out of Scope for v0.5
- `estimate_gas` tool — Casper does not expose gas estimation via RPC; would require mock pricing
- Price alerts / webhooks — no persistent connection in MCP protocol

## Success Criteria for v0.5
- Error messages include actionable next steps in at least 5 common failure scenarios
- SDK types fully exported and documented
- Items 1-3 shipped with unit tests
- No breaking changes to existing tool signatures
