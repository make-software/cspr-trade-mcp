## Production Notes

### Firefly Workflow
1. **Style preset:** Select "Claymation" for all generations
2. **Image-first approach:** Generate each scene as a still image first, refine until happy, then use image-to-video to animate
3. **Character consistency:** Use Firefly's custom model training to create the main developer character once, then reuse across all scenes
4. **Color palette:** Warm earth tones (clay browns, oranges) with Casper red (#FF0000) as accent color
5. **Aspect ratio:** 16:9 for YouTube/social

### Post-Production (Premiere Pro)
- Stitch all clips sequentially
- Add text overlays per scene notes above
- Add voiceover (record or TTS)
- Add background music — search Adobe Stock for "quirky stop-motion" or "playful claymation"
- Add subtle sound effects: clay thuds, paper rustling, keyboard clicks

### Voiceover Options
- **Option A:** Record Michael or a team member (authentic feel)
- **Option B:** AI voice — warm, friendly male voice, conversational pace
- **Option C:** No voiceover — text-only with music (simpler but less engaging)
