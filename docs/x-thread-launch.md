## Tweet 2
One line of config:

```json
{
  "mcpServers": {
    "cspr-trade": {
      "url": "https://mcp.cspr.trade/mcp"
    }
  }
}
```

That's it. Claude Desktop, Cursor, or any MCP client — your agent now talks to Casper DeFi.
